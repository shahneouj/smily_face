# SDL3 Framebuffer

A small software framebuffer project written in **C** using **SDL3**.

The project is built from scratch to understand how pixels, framebuffers, textures, rendering, animation, and frame timing work at a low level.

## Features

- C99
- SDL3
- Software framebuffer
- Custom `put_pixel()` function
- Direct pixel manipulation
- 320×200 framebuffer
- 2× pixel scaling to a 640×400 window
- Animated bouncing smiley face
- Animated blinking eyes
- 60 FPS frame timing
- CMake build system

## How It Works

The project uses a simple rendering pipeline:

```text
             CPU
              │
              │ Draw pixels
              ▼
      ┌─────────────────┐
      │   Framebuffer   │
      │    320 × 200    │
      └────────┬────────┘
               │
               │ SDL_UpdateTexture()
               ▼
      ┌─────────────────┐
      │     Texture     │
      │    320 × 200    │
      └────────┬────────┘
               │
               │ SDL_RenderTexture()
               ▼
      ┌─────────────────┐
      │    Renderer     │
      └────────┬────────┘
               │
               │ SDL_RenderPresent()
               ▼
      ┌─────────────────┐
      │     Window      │
      │    640 × 400    │
      └─────────────────┘
```

The framebuffer is simply an array of pixels:

```c
uint32_t framebuffer[WINDOW_WIDTH * WINDOW_HEIGHT];
```

Each pixel can be changed with:

```c
put_pixel(x, y, color);
```

The 2D coordinate is converted into a 1D array index:

```c
framebuffer[y * WINDOW_WIDTH + x] = color;
```

## Animation

The smiley face position is calculated using `sin()`:

```c
int y =
    WINDOW_HEIGHT / 2 +
    (int)(sin(time * 3.0f) * 20.0f);
```

This produces a smooth up-and-down movement.

The program also uses time to control blinking.

## Requirements

You need:

- GCC or another C compiler
- CMake
- SDL3
- Make or another supported build tool

On Debian/Ubuntu-based systems, make sure SDL3 development files are installed and available to CMake.

## Build

Clone the repository:

```bash
git clone <repository-url>
cd framebuffer
```

Create the build directory:

```bash
cmake -S . -B build
```

Build the project:

```bash
cmake --build build
```

## Run

Run the executable directly:

```bash
./build/framebuffer
```

Or use the CMake `run` target:

```bash
cmake --build build --target run
```

## CMake

The project links against SDL3 and the Linux math library:

```cmake
target_link_libraries(framebuffer PRIVATE
    SDL3::SDL3
    m
)
```

The `m` library is required for mathematical functions such as:

```c
sin()
fmod()
```
